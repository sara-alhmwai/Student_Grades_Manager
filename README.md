Student Grades Manager

A beginner-friendly Python project for managing student grades through a simple menu-driven program.

Features

- Add students and their grades.
- Display student names and grades in Math, English, and Python.
- Calculate the average grade for each student.
- Determine whether a student passed or failed based on an average of 50.
- Validate grades to ensure they are between 0 and 100.
- Handle invalid numeric input.

Technologies Used

- Python

How to Run

1. Install Python.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run:
   
   "python student_grades_manager.py"

Concepts Practiced

- Functions
- Lists and dictionaries
- Loops and conditional statements
- Exception handling ("try" / "except")
- Input validation
- Working with user input
